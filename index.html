طبّق خوارزمية K-Means على البيانات دي بعدد عناقيد K = 2، ولمدة تكرارين (2 iterations)، وبيّن العناقيد الناتجة:

     (179, 68), (182, 72), (188, 77)}

عدد العناقيد K = 2 (نسمّيهم c1 و c2)، وعدد التكرارات المطلوبة اتنين.

1️⃣ المراكز الأولية (Initial Centroids)
c1 = (185, 72) ← first object
c2 = (170, 56) ← second object

بناخد أول نقطتين من البيانات زي ما هم، من غير أي حساب.

2️⃣ التكرار الأول (Iteration 1) — نحسب المسافة الإقليدية
d(A, B) = √((x₂ − x₁)² + (y₂ − y₁)²)

مثال للنقطة 3:

d(c1, 3) = √((185−168)² + (72−60)²) = √(289 + 144) = √433 = 20.81
d(c2, 3) = √((170−168)² + (56−60)²) = √(4 + 16) = √20 = 4.47

بما إن d(c2, 3) أصغر من d(c1, 3)، يبقى النقطة 3 بتنضم لـ c2. وبنفس الطريقة لكل النقط:

4️⃣ التوقف (Stop Training)

إحنا كمّلنا التكرارين اللي السؤال طلبهم، وكمان التوزيع ثبت ومتغيّرش → بنوقف الخوارزمية (convergence) حتى لو السؤال طلب تكرارات أكتر.

وده نفس فكرة سؤال «توقّف الـ K-Means» في الكويز: بنقف لما المراكز تبقى تقريبًا مش بتتغيّر.

ملحوظة: لو طلبوا تكرار تالت، هتطلع نفس المراكز ونفس العناقيد — يعني الإجابة مش هتتغيّر.

🎯 الترتيب اللي بتحل بيه أي مسألة K-Means

1️⃣ حدّد K والمراكز الأولية — غالبًا أول K نقط، أو زي ما السؤال يقول.

2️⃣ احسب مسافة كل نقطة لكل مركز، ووزّعها على المركز الأقرب.

3️⃣ حدّث كل مركز بحيث يبقى متوسط إحداثيات نقاط عنقوده.

4️⃣ كرّر لحد ما التوزيع والمراكز يثبتوا، وبعدها قف.
